# كتابي الذكي

واجهة منصة تعليمية عربية (RTL) قابلة للتطوير والنشر على GitHub Pages.

## المزايا الحالية
- واجهة تسجيل دخول إلزامية.
- تسجيل بالبريد الإلكتروني مع رمز OTP عبر Supabase عند ضبط الإعدادات.
- خيار رقم الهاتف/واتساب مع نقطة ربط خادم WhatsApp Business API.
- الصفوف: التاسع، الأول الثانوي، الثالث الثانوي.
- المواد العلمية واللغوية كنموذج أولي قابل للتعديل.
- أربعة أقسام داخل كل مادة: الكتاب، الكتاب المحلول، النماذج الوزارية، الاختبار الوزاري.
- تصميم متجاوب للهاتف والكمبيوتر.

## التشغيل محلياً
افتح `index.html` في المتصفح أو استخدم خادماً محلياً:
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## تفعيل رمز البريد الإلكتروني
1. أنشئ مشروعاً في https://supabase.com
2. افتح Project Settings > API.
3. انسخ Project URL و anon/public key.
4. ضع القيم في `config.js`.
5. فعّل Email provider من Authentication > Providers.
6. من Authentication > URL Configuration أضف رابط موقعك إلى Site URL و Redirect URLs.
7. جرّب تسجيل الدخول ببريدك.

> لا تضع `service_role` key في ملفات الواجهة أبداً. في الإنتاج، اضبط سياسات قاعدة البيانات (RLS) واحمِ كل ملفات المحتوى الخاصة على الخادم. إخفاء الصفحات في JavaScript وحده ليس حماية للمحتوى.

## تفعيل واتساب
خيار واتساب في الواجهة لا يرسل رمزاً تلقائياً. يحتاج خادماً خلفياً آمناً يتصل بـ WhatsApp Business Platform أو مزود رسمي مثل Twilio، ويحتوي مسارين:
- `POST /api/whatsapp/send-otp` لإرسال الرمز.
- `POST /api/whatsapp/verify-otp` للتحقق من الرمز وإنشاء جلسة دخول آمنة.

لا تضع رموز API السرية في `config.js` أو GitHub. يجب أن يتحقق الخادم من الرمز قبل منح المستخدم جلسة.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع جميع ملفات هذا المشروع إلى جذر المستودع.
3. افتح Settings > Pages.
4. اختر Deploy from a branch ثم `main` و `/ (root)`.
5. احفظ وانتظر رابط الموقع.
6. أضف رابط GitHub Pages إلى Supabase Redirect URLs.

## ملاحظات مهمة قبل الإطلاق
- المحتوى المعروض حالياً هيكل تجريبي؛ أضف ملفات الكتب PDF والدروس الفعلية لكل صف ومادة.
- أسماء المواد قابلة للتعديل في مصفوفة `subjects` داخل `app.js`.
- الاختبار الوزاري يحتاج بنك أسئلة، إجابات صحيحة، ونظام تصحيح وحفظ نتائج على قاعدة بيانات.
- إذا كان المحتوى مدفوعاً أو خاصاً، لا تستخدم GitHub Pages وحده لحمايته؛ استخدم خادماً وقواعد صلاحيات.
